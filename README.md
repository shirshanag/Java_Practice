Welcome to the Java Basics & Object-Oriented Programming (OOPs) repository!
This repo contains simple, well-structured programs to help you learn and master core Java concepts — from basic syntax to advanced OOP principles.

About

This repository is designed for students and developers who want to strengthen their understanding of Java fundamentals and Object-Oriented Programming concepts through hands-on examples.

Each topic folder contains:

Source code (.java files)

Comments explaining each line

Example outputs

Practice questions
